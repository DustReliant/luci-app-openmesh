# ADR-0006 V0.1 采用原生 UCI 静态 802.11s，mesh11sd 延后至 V0.2

- 状态：已接受（2026-10-23）
- 影响版本：V0.1（M7）

## 背景

原 V0.1 有「Mesh 创建/加入」但 802.11s 列在 V0.2，范围含糊。

## 决策

V0.1 的建网/入网使用 **OpenWrt 原生 wireless UCI 静态配置**（`config wifi-iface` + `option mode 'mesh'` + `option mesh_id` + SAE，23.05/24.10/25.x 原生支持），不引入 mesh11sd。mesh11sd（动态多 radio 管理）与 batman-adv 在 V0.2 集成。

## 理由

- 静态单 radio 11s 是 OpenWrt 原生能力，V0.1 即可交付「真·可用的两节点 Mesh」端到端体���
- mesh11sd 服务于动态/多 radio/漫游式 11s 管理场景，属 V0.2 数据面完整化的范畴
- 最小依赖原则：V0.1 新增依赖仅 wpad-mesh-mbedtls + 加密库

## 后果

- V0.1 拓扑/链路数据只需覆盖模式 A（无线）
- M7 的配置生成器输出结构需为 V0.2 模式 B 预留扩展（backhaul.mode 字段已在 UCI schema 中）
- 「Mesh 加入」在 V0.1 语义 = Agent 接受 Controller 下发的 wireless UCI 并生效
