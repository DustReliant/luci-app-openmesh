# ADR-0007 V0.2 不集成 mesh11sd，维持原生 UCI 静态 802.11s

- 状态：已接受（2026-10-24）
- 影响版本：V0.2

## 背景

roadmap V0.2 原列"mesh11sd 集成"。评估结论：推迟。

## 理由

1. **配置所有权冲突**：mesh11sd 是 /etc/config/wireless 的第二个写者（动态启停/调参 11s 接口），与本项目 netconf 事务引擎（快照/确认/回滚）在同一文件上双写，回滚语义无法保证——要么 mesh11sd 受控为唯一写者（则我们的 mesh_create/事务安全网失效），要么我们关闭其动态特性（则它只剩静态配置等价物）。
2. **V0.2 场景不需要动态性**：单 radio 静态 11s + batman-adv 模式 B 全部经 UCI 静态表达；mesh11sd 的价值（多 radio 动态管理、运行时参数调优、vxlan 等）属 V0.4"回程优化"范畴。
3. **依赖最小化**（项目原则）：少一个常驻 daemon，少一份内存/闪存开销。

## 后续

- V0.4 评估"受控集成"：netconf 事务包住 mesh11sd 的配置变更，或自研参数调优（届时依据 01 调研的 mesh11sd UCI 全量选项再决策）。
- 本 ADR 推翻条件：双 radio 异频回程需求提前出现。
