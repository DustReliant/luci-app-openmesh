# 模块设计文档

每个功能模块（M0–M8，见 [../roadmap.md](../roadmap.md)）在**开工前**在此目录建一份设计文档 `m<N>-<slug>.md`，必须包含「开工前 10 问」的完整回答（见 [../workflow.md](../workflow.md) §3）；实现完成后回填实际接口与偏差说明。

## 模板

```markdown
# M<N> <模块名>

状态：起草 | 实现中 | 已交付（commit: <hash>）

## 开工前 10 问
1. 解决什么问题：
2. OpenWrt 原生能力：
3. 可复用项目：
4. 为什么自己开发：
5. 与其他模块的交互：
6. 配置存储与持久化：
7. ubus API（方法/参数/返回/ACL）：
8. 错误与恢复（超时/回滚/崩溃/掉电）：
9. 测试（DoD 可执行断言）：
10. 版本兼容（差异点/退化策略）：

## 设计
（接口、数据结构、状态机、帧格式、资源预算……）

## 待验证项
（不确定的 OpenWrt API + 验证方法 + 验证结果回填）

## 实现后回填
（实际接口、与设计的偏差及原因、遗留问题）
```
